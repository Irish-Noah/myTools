### How to use the Spotify Tracker
Run the program in your terminal. It will open a browser with the Authorization URI automatically. Wait for the page to load and copy the string after 'code=' in the url. Then paste the code into the terminal and hit enter for the program to continue. It will then tell you how many albums you have listened to this year and compare them to the number of days that have passed this year so far! 

I use this tool all the time. Saves me so much time for my 'album a day' challenge!
